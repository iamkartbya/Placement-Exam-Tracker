# AI-Powered Placement Notification Automation

**Developed by:** Kartbya Kumar  
**Project Type:** Workflow Automation  
**Technology:** n8n, Gmail, Google Calendar, AI/LLM integrations

## About the Project

This project is an automated placement notification management system developed using n8n. It monitors placement-related emails from multiple Gmail sources and the Sathyabama 2027 Google Group.

The workflow processes incoming emails and attachments to extract relevant placement information and organize important updates.

## Main Features

1. **Multiple Email Sources**
   - Monitors multiple Gmail accounts or email sources.
   - Receives placement notifications from the Sathyabama 2027 Google Group.

2. **Automated Email Processing**
   - Detects new placement-related emails.
   - Reads email content and attachments.
   - Extracts relevant placement information.

3. **Placement Information Analysis**
   - Processes placement announcements.
   - Identifies relevant student information and registration details.
   - Handles shortlisted and off-campus application information.

4. **Google Calendar Integration**
   - Automatically organizes relevant placement events in Google Calendar.
   - Adds event dates, start times, end times and descriptions.

5. **Workflow Automation**
   - Reduces manual email checking.
   - Centralizes placement notifications.
   - Helps students stay informed about placement opportunities.

## Technologies Used

- n8n – Workflow Automation
- Gmail API – Email monitoring
- Google Groups – Placement notification source
- Google Calendar API – Event management
- AI/LLM integrations – Information processing (where configured)

## Installation and Setup

1. Install and run n8n.
2. Import the provided `Placement Exam Tracker.json`.
3. Configure your own Gmail credentials.
4. Configure Google Calendar credentials.
5. Set up any required AI/API credentials.
6. Test the workflow and activate it.
